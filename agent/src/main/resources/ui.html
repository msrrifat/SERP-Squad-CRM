Chrome IDs

          
Separate Chrome profiles that you sign in to once: one per Google account or social login. In each project's Work setup you choose which Chrome ID a channel uses. The agent never types passwords or codes; if a site asks again, it stops and tells you.

          

          

          

          
  1. Add a Chrome ID and press Sign in. Chrome opens with that profile.
  2. Sign in to the account yourself, then close that Chrome window. The sign-in is kept.
  3. In the project's Work setup, choose this Chrome ID for the channel it manages.

Chrome IDs

          
Separate Chrome profiles that you sign in to once: one per Google account or social login. In each project's Work setup you choose which Chrome ID a channel uses. The agent never types passwords or codes for these accounts; if a site asks again, it stops and tells you. (The only sign-ins the program types itself are the ones you save for SEO tools, on this screen.)

          

          

          

          
  1. Add a Chrome ID and press Sign in. Chrome opens with that profile.
  2. Sign in to the account yourself, then close that Chrome window. The sign-in is kept.
  3. In the project's Work setup, choose this Chrome ID for the channel it manages.

        

        

          
Saved sign-ins for SEO tools

          
For paid tools your agency has an account with (a backlink index, a keyword tool). When a tool has signed the agent out, the program types the saved user name and password into that tool's own sign-in page. They are stored encrypted on this computer only: never sent to the CRM, never given to Claude, and not shown again after saving. Not for Google, Microsoft, Apple or Facebook accounts: sign in to those yourself in the Chrome ID. A tool that asks for a code or a captcha still needs you.

          

          
          
          
          
          

          

          

          
  1. In the CRM (AI agent, API setup, SEO tools) add the tool and choose the Chrome ID it uses.
  2. Under Chrome IDs here, press Sign in for that Chrome ID and sign in to the tool once yourself.
  3. Save the sign-in here, so the agent can sign in again when the tool signs it out.

        

        

          
This computer

          
The agent runs here: its own program, its Chrome windows and its working files use this computer's processor, memory and disk. The CRM server only keeps the records (tasks, reports, what the agent knows about each project).

          

          

          

          
The working folder has one folder per project: the agent's own notes and inventories, copies of pictures it fetched from Google Drive, and its copy of a website's code. It reads these before fetching anything again.

        

        

          
This application

          

          

          

          
New versions come from the CRM. The agent installs them by itself, between tasks; this button checks right now. The window reloads when the new version has started.

          
Start the agent when this computer starts

          

          
With this on, the agent comes back by itself after a power cut and carries on with the task it was in the middle of. The computer itself also has to switch on again when power returns (a setting in its BIOS, usually "Restore on AC power loss") and sign this user in without waiting for a password.

          
Closing this window does not stop the agent. Use the SERP Squad icon near the clock to open the window again, pause, or quit.
